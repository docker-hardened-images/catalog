## About OpenTelemetry eBPF Reducer

The reducer is a component of the [OpenTelemetry eBPF](https://github.com/open-telemetry/opentelemetry-network) project.
It aggregates and enriches network telemetry data streamed from OpenTelemetry eBPF collectors, optionally enriching it
with AWS EC2 metadata, GeoIP, and Kubernetes metadata, and exports the resulting metrics via a Prometheus scrape
endpoint or OTLP/gRPC.
