## About Forklift Hyper-V Provider Server

[Forklift](https://github.com/kubev2v/forklift) migrates virtual machines from other platforms to KubeVirt. The Hyper-V
provider server backs Hyper-V migration sources: it keeps the SMB export of the source disks mounted in the cluster and
answers disk-path validation requests from the Forklift controller while plans are prepared.

## About Docker Hardened Images

Docker Hardened Images are built to meet the highest security and compliance standards. They provide a trusted

These images are published with near-zero known CVEs, include signed provenance, and come with a complete Software Bill
