## About Kargo

Kargo is an open-source project from Akuity that promotes application artifacts through the stages of their lifecycle.
Its control plane includes an API server and a controller. The project home is [kargo.io](https://kargo.io/), the source
is [akuity/kargo](https://github.com/akuity/kargo), and the license is Apache-2.0.

This Docker Hardened Image replaces `ghcr.io/akuity/kargo` and includes the Helm CLI that promotions use to render and
install charts.
