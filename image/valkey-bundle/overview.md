## About Valkey Bundle

Valkey Bundle packages the Valkey data structure server together with four community Valkey modules: `valkey-json`
(native JSON documents), `valkey-bloom` (Bloom filters), `valkey-search` (vector search and secondary indexing), and
`valkey-ldap` (LDAP authentication). Valkey is an open source, high-performance data structure server forked from Redis
before its license change, and continues the tradition of in-memory speed and simplicity with open governance and
community-driven development.

For more details, visit https://valkey.io and https://github.com/valkey-io/valkey-bundle
