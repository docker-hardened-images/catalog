## About RabbitMQ Messaging Topology Operator

The RabbitMQ Messaging Topology Operator is a Kubernetes operator that declares RabbitMQ vhosts, queues, exchanges,
users, and policies as custom resources. It reconciles those objects onto a RabbitMQ cluster.

This image replaces `ghcr.io/rabbitmq/messaging-topology-operator`. Follow the
[topology operator install guide](https://www.rabbitmq.com/kubernetes/operator/install-topology-operator) and the
[project repository](https://github.com/rabbitmq/messaging-topology-operator) for install steps and product
documentation.
