## About httpbin

httpbin is an HTTP request and response testing service, maintained as Kong's fork of the original postmanlabs/httpbin
project by Kenneth Reitz. It is a Flask application, served by gunicorn with the gevent worker, that exposes a set of
HTTP endpoints for testing HTTP clients, libraries, proxies, and API integrations — covering request inspection, status
codes, authentication schemes, redirects, response headers, and content encoding.
