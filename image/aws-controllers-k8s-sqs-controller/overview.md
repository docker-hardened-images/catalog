## About AWS Controllers for Kubernetes (ACK) SQS controller

The AWS Controllers for Kubernetes (ACK) SQS controller is a Kubernetes controller that manages Amazon Simple Queue
Service (Amazon SQS) queues. You declare a `Queue` custom resource, and the controller creates, updates and deletes the
matching queue in AWS. The project is documented at https://github.com/aws-controllers-k8s/sqs-controller and the
umbrella ACK documentation is at https://aws-controllers-k8s.github.io/community/.

## About Docker Hardened Images

Docker Hardened Images are built to meet the highest security and compliance standards. They provide a trusted

### Why use Docker Hardened Images?

These images are published with near-zero known CVEs, include signed provenance, and come with a complete Software Bill
of Materials (SBOM) and VEX metadata. They're designed to secure your software supply chain while fitting seamlessly
into existing Docker workflows.
