## About RabbitMQ Cluster Operator

The RabbitMQ Cluster Kubernetes Operator deploys and manages RabbitMQ clusters on Kubernetes. It watches RabbitmqCluster
custom resources and reconciles them into workloads, services, and configuration. This image is the operator, and the
RabbitMQ message broker is published as a separate image. For project details, see
https://www.rabbitmq.com/kubernetes/operator/operator-overview.html and https://github.com/rabbitmq/cluster-operator.
