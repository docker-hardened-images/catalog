## About OpenLDAP

OpenLDAP Software is an open source implementation of the Lightweight Directory Access Protocol (LDAP) developed by the
OpenLDAP Project. Its stand-alone LDAP daemon, slapd, listens for LDAP connections and answers the directory operations
it receives, with dynamically loaded backends such as MDB and overlays such as password policy, sync replication and
access logging. The image also carries the OpenLDAP client tools, including ldapsearch, ldapadd and ldapmodify.
