## About Ory Hydra

Ory Hydra is an OAuth 2.0 server and OpenID Connect provider. It issues access, refresh and ID tokens and connects to an
existing identity system through a login and consent app, so the user interface stays under your control. It stores
clients, sessions and keys in PostgreSQL, MySQL, CockroachDB or SQLite, and can keep its signing keys in a hardware
security module through PKCS#11.

This Docker Hardened Image is the hardened stand-in for the upstream image `oryd/hydra`. The project is published at
https://github.com/ory/hydra.
