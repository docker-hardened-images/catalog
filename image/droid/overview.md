## About Factory Droid

[Factory Droid](https://docs.factory.ai/cli) is an agentic coding CLI. This image packages it for Docker Sandboxes with
the agent user and Docker-in-Docker.

## About Docker Hardened Images

### Why use Docker Hardened Images?

Docker Hardened Images provide signed provenance, an SBOM, and VEX metadata.
