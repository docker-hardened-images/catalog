## About Crossplane Provider AWS SNS

The Crossplane provider for Amazon Web Services (AWS) lets Crossplane manage AWS resources as Kubernetes objects. It is
split into a family of provider packages. The SNS service provider in this image manages Amazon Simple Notification
Service (SNS) resources, for example topics, topic policies, and subscriptions. It reads its AWS credentials through the
`ProviderConfig` APIs of the family provider, which is a separate package.

For more details, visit https://github.com/crossplane-contrib/provider-upjet-aws.

## About Docker Hardened Images

Docker Hardened Images are built to meet the highest security and compliance standards. They provide a trusted

These images are published with near-zero known CVEs, include signed provenance, and come with a complete Software Bill
