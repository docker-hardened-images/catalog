## About Dev Containers Base

Dev Containers Base is a minimal operating system image for development containers, as described by the
[Development Containers specification](https://containers.dev/). It ships a non-root `vscode` user with passwordless
`sudo`, `git`, `zsh` and the command-line tooling that IDEs and editors expect to find when they attach to a container.
It carries no language runtime, so you add the runtimes and tools your project needs on top.

For more details, visit [containers.dev](https://containers.dev/) and the upstream
[devcontainers/images](https://github.com/devcontainers/images) repository.

## About Docker Hardened Images

Docker Hardened Images are built to meet the highest security and compliance standards. They provide a trusted
foundation for containerized workloads by incorporating security best practices from the start.

### Why use Docker Hardened Images?

These images are published with near-zero known CVEs, include signed provenance, and come with a complete Software Bill
of Materials (SBOM) and VEX metadata. They're designed to secure your software supply chain while fitting seamlessly
into existing Docker workflows.
