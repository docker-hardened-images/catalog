## About Apache Solr

Apache Solr is an open-source, enterprise-grade search platform built on Apache Lucene. It provides full-text search,
faceted search, hit highlighting, dynamic clustering, rich document handling, and geospatial search across a wide range
of use cases from e-commerce to enterprise content management. Solr is horizontally scalable and designed for high
availability through its SolrCloud distributed mode, which offers automatic replication, sharding, and leader election.

For more information, see the [Apache Solr website](https://solr.apache.org/).

## About Docker Hardened Images

Docker Hardened Images are built to meet the highest security and compliance standards. They provide a trusted

These images are published with near-zero known CVEs, include signed provenance, and come with a complete Software Bill
