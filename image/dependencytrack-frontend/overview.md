## About Dependency-Track Frontend

Dependency-Track Frontend is the web interface for [OWASP Dependency-Track](https://dependencytrack.org/), an
open-source platform that tracks components and vulnerabilities from software bills of materials. This image serves that
Vue single-page application with nginx and replaces `dependencytrack/frontend`. It does not include the Dependency-Track
API.

Published tags follow the 5.x and 4.x release lines. The 4.x line reaches end of life on 2026-12-31. Project
documentation is at https://dependencytrack.org/.

## About Docker Hardened Images

Docker Hardened Images are built to meet the highest security and compliance standards. They provide a trusted
foundation for containerized workloads by incorporating security best practices from the start.

### Why use Docker Hardened Images?

These images are published with near-zero known CVEs, include signed provenance, and come with a complete Software Bill
of Materials (SBOM) and VEX metadata. They're designed to secure your software supply chain while fitting seamlessly
into existing Docker workflows.
