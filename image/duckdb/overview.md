## About DuckDB

DuckDB is an in-process analytical SQL database. This image is the command-line shell for running local analytical SQL,
including queries over Parquet files.

The shell is documented at https://duckdb.org/docs/current/clients/cli. The upstream project is published at
https://github.com/duckdb/duckdb and https://duckdb.org.
