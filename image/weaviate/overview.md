## About Weaviate

Weaviate is an open-source, AI-native vector database. It stores data objects together with their vector embeddings
and serves fast vector, keyword (BM25), and hybrid search over them, with filtering, multi-tenancy, replication, and
horizontal scaling. Weaviate exposes a REST and GraphQL API on port 8080 and a gRPC API on port 50051, integrates with
many embedding and generative model providers through modules, and is written in Go. For more details, visit
https://weaviate.io.

## About Docker Hardened Images

Docker Hardened Images are built to meet the highest security and compliance standards. They provide a trusted

These images are published with near-zero known CVEs, include signed provenance, and come with a complete Software Bill
