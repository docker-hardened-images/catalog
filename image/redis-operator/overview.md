## About Redis Operator

The OpsTree Redis Operator deploys and manages Redis, Redis Cluster, Redis replication, and Redis Sentinel on
Kubernetes. It reconciles custom resources from the redis.redis.opstreelabs.in API group.

This image replaces quay.io/opstree/redis-operator:v0.26.0 and is licensed under Apache-2.0. See
https://redis-operator.opstree.dev/ and https://github.com/OT-CONTAINER-KIT/redis-operator.
