## About Playwright

Playwright is a framework for web automation and testing. It drives Chromium, Firefox, and WebKit with a single API,
letting teams write end-to-end tests, browser automation scripts, and AI agent tooling that behave consistently across
all three browser engines.

Playwright is commonly used in CI/CD pipelines for cross-browser end-to-end testing, in headless scraping and automation
scripts, and as a driver for AI agents that need to interact with real web pages.
