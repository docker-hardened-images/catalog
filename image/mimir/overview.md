## About Grafana Mimir

Grafana Mimir is an open source, horizontally scalable, highly available, multi-tenant, long-term storage backend for
Prometheus metrics. It provides unlimited cardinality and long-term metric retention with a fully Prometheus-compatible
query API, built-in multi-tenancy, and support for high-availability clustering.

Mimir can run as a single process in monolithic mode for smaller deployments, or as independent microservices for
large-scale, production-grade deployments. It supports storage backends including Amazon S3, Google Cloud Storage, Azure
Blob Storage, and local filesystem storage.

Official documentation: https://grafana.com/docs/mimir/
