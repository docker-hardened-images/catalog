## About GitHub Copilot

[GitHub Copilot](https://github.com/github/copilot-cli) is an agentic coding CLI. This image packages it for Docker
Sandboxes with the agent user and Docker-in-Docker.

## About Docker Hardened Images

### Why use Docker Hardened Images?

Docker Hardened Images provide signed provenance, an SBOM, and VEX metadata.
