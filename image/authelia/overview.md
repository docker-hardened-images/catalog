## About Authelia

Authelia is an open-source authentication and authorization server that provides a login portal, single sign-on, and
multi-factor authentication for web applications. It is OpenID Certified™ and is licensed under the Apache License 2.0.

Use this image to run the Authelia portal. Configuration and deployment guidance is at https://www.authelia.com.

## About Docker Hardened Images
