## About Kafdrop

Kafdrop is a web UI for viewing Apache Kafka topics and browsing consumer groups. It displays brokers, topics,
partitions, consumer groups and their lag, and lets you view messages in JSON, plain text, Avro and Protobuf encodings.
Kafdrop is a lightweight Spring Boot application that supports SASL and TLS-secured brokers.
