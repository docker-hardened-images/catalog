## About cloudflared

cloudflared is the command-line client for Cloudflare Tunnel™. It connects an origin service to the Cloudflare® network
without opening inbound ports on that origin.

This Docker Hardened Image is the hardened stand-in for the upstream image `docker.io/cloudflare/cloudflared`. The
project is published at https://github.com/cloudflare/cloudflared.
