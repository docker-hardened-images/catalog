## About Vaultwarden

Vaultwarden is an unofficial Bitwarden-compatible password server written in Rust, with the web vault included. It
stores vault data in `/data` and serves the API and the web interface on a single port. This image replaces
vaultwarden/server with a hardened build of the [dani-garcia/vaultwarden](https://github.com/dani-garcia/vaultwarden)
server.
