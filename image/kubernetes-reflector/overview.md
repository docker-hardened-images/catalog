## About Kubernetes Reflector

Kubernetes Reflector is a Kubernetes controller that copies Secrets and ConfigMaps into other namespaces and keeps each
copy in sync with its source. You opt in with annotations on the source object. It works with cert-manager, so a TLS
certificate that cert-manager issues can be shared across namespaces.
