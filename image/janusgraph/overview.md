## About JanusGraph

JanusGraph is a scalable, distributed graph database optimized for storing and querying graphs containing billions of
vertices and edges across a multi-machine cluster. It is a transactional database that can support thousands of
concurrent users, complex traversals, and analytic graph queries. JanusGraph is built on the Apache TinkerPop graph
computing framework and supports pluggable storage backends (such as Apache Cassandra, Apache HBase, and BerkeleyDB) and
index backends (such as Elasticsearch, Apache Solr, and Apache Lucene).

For more information and related downloads, visit https://janusgraph.org/.
