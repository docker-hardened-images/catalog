## About PgBouncer Exporter

PgBouncer Exporter is a Prometheus exporter for PgBouncer, the lightweight connection pooler for PostgreSQL. It connects
to PgBouncer's statistics interface and exposes pool metrics — including client and server connection counts, pool
utilisation, query wait times, and bytes transferred — in Prometheus format on port 9127.

Official documentation: https://github.com/prometheus-community/pgbouncer_exporter
