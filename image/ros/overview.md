## About ROS 2

The Robot Operating System (ROS™) is a set of software libraries and tools that help you build robot applications, from
drivers to state-of-the-art algorithms, with powerful developer tools. This image provides the ROS 2 base set: the C++
and Python client libraries, the `ros2` command line tools, launch, rosbag2, tf2 and URDF, communicating over Fast DDS.
