## About KeyDB

KeyDB is a high-performance fork of Redis that runs the event loop on multiple threads and remains fully compatible with
the Redis protocol, modules and scripts. On top of the Redis feature set it adds active replication and multi-master
topologies for hot-spare failover, and an optional FLASH storage provider that spills data to SSD.

For more details, visit https://docs.keydb.dev.

## About Docker Hardened Images

Docker Hardened Images are built to meet the highest security and compliance standards. They provide a trusted

These images are published with near-zero known CVEs, include signed provenance, and come with a complete Software Bill
