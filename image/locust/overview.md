## About Locust

Locust is an open-source, MIT-licensed load-testing tool: you define user behaviour in plain Python code, and a web UI
shows request statistics in real time. It can run distributed, with a master coordinating workers on one or more
machines to generate more load. This image comes in runtime and dev variants, each with a FIPS version, on Debian and
Alpine. Project documentation is at <https://docs.locust.io/>.
