## About LiteLLM Database

LiteLLM Database is the database-enabled LiteLLM proxy image for running a persistent AI gateway with PostgreSQL-backed
virtual keys, budgets, spend tracking, and model configuration. It provides an OpenAI-compatible API for 100+ LLM
providers and includes the generated Prisma client needed for LiteLLM database operations.

For more information, see the LiteLLM documentation at https://docs.litellm.ai/docs/ and the upstream source repository
at https://github.com/BerriAI/litellm.
