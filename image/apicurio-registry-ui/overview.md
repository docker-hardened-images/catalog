## About Apicurio Registry UI

Apicurio Registry UI is the web console for [Apicurio Registry](https://www.apicur.io/registry/), a registry for schemas
and API designs such as Avro, Protobuf, JSON Schema, OpenAPI, and AsyncAPI. This image serves the UI with nginx and
replaces `apicurio/apicurio-registry-ui`; it does not include the Registry server, whose REST API the UI calls from the
browser.

Tags follow the 3.3 and 3.2 release lines on Debian 13 and Alpine 3.24, and project documentation is at
https://www.apicur.io/registry/docs/.
