## About HashiCorp Consul

Consul is HashiCorp's service networking solution for discovering, configuring, and securing services across dynamic,
distributed infrastructure. It provides a distributed service registry with health checking, a hierarchical key-value
store for configuration, and both DNS- and HTTP-based service discovery.

Consul's service mesh secures service-to-service communication with mutual TLS and intention-based authorization, and it
integrates with Kubernetes, virtual machines, and cloud platforms. A built-in web UI, HTTP API, and CLI provide
operational visibility into the cluster.

For more details, see https://developer.hashicorp.com/consul.

## About Docker Hardened Images

Docker Hardened Images are built to meet the highest security and compliance standards. They provide a trusted
foundation for containerized workloads by incorporating security best practices from the start.

### Why use Docker Hardened Images?

These images are published with near-zero known CVEs, include signed provenance, and come with a complete Software Bill
of Materials (SBOM) and VEX metadata. They're designed to secure your software supply chain while fitting seamlessly
into existing Docker workflows.
