## About Qdrant

Qdrant is an open-source vector database and similarity-search engine for the next generation of AI applications. It
stores high-dimensional vectors alongside JSON payloads and serves fast, filtered nearest-neighbor search built on a
custom HNSW index, making it a foundation for semantic search, recommendations, and retrieval-augmented generation.
Qdrant exposes both a REST API on port 6333 and a gRPC API on port 6334, ships a built-in web dashboard, and is written
in Rust for performance and memory safety. For more details, visit https://qdrant.tech.

## About Docker Hardened Images

Docker Hardened Images are built to meet the highest security and compliance standards. They provide a trusted
foundation for containerized workloads by incorporating security best practices from the start.

### Why use Docker Hardened Images?

These images are published with near-zero known CVEs, include signed provenance, and come with a complete Software Bill
of Materials (SBOM) and VEX metadata. They're designed to secure your software supply chain while fitting seamlessly
into existing Docker workflows.
