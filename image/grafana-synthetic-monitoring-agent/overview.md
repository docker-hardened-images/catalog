## About Grafana Synthetic Monitoring Agent

Grafana Synthetic Monitoring Agent is the probe agent from Grafana Labs that runs synthetic checks for Grafana Cloud
Synthetic Monitoring from a private network. It runs HTTP, ping, DNS, TCP and scripted checks. The upstream project is
[grafana/synthetic-monitoring-agent](https://github.com/grafana/synthetic-monitoring-agent), licensed under Apache-2.0
AND AGPL-3.0-only.
