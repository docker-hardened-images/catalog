## About Rclone

Rclone is a command-line program to sync files and directories to and from different cloud storage providers. It works
with over 70 cloud storage products, including S3 object stores, business and consumer file storage services, and
standard transfer protocols such as SFTP, WebDAV and FTP.

Rclone has cloud equivalents of the Unix commands rsync, cp, mv, ls, rm and cat, and it can serve a remote over HTTP,
WebDAV, SFTP, FTP or the S3 API. This image ships the rclone CLI without FUSE mount support.
