## About OpenSpeedTest

OpenSpeedTest is a self-hosted HTML5 network speed test. Run it on a network you control and open the page in a browser
to measure download speed, upload speed, and latency. This image serves that page with nginx on HTTP port 3000 and HTTPS
port 3001.

It replaces the upstream `openspeedtest/latest` image. The project home is https://openspeedtest.com, the source is
https://github.com/openspeedtest/Speed-Test, and the license is MIT.
