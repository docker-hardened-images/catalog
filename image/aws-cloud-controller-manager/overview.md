## About AWS Cloud Controller Manager

The AWS Cloud Controller Manager connects Kubernetes® clusters to AWS service APIs. It manages cloud node lifecycle,
routes, and AWS load balancers for Kubernetes Service resources.

This image contains the AWS provider implementation from
[`kubernetes/cloud-provider-aws`](https://github.com/kubernetes/cloud-provider-aws). See the
[upstream documentation](https://cloud-provider-aws.sigs.k8s.io/) for deployment requirements and configuration.
