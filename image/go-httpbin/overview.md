## About go-httpbin

go-httpbin is a Go port of httpbin, an HTTP request and response service for testing HTTP clients, libraries, and
proxies. It echoes requests back as JSON and serves endpoints for status codes, headers, redirects, authentication,
streaming, and WebSocket echo, with no dependencies outside the Go standard library.

This hardened image is built from the official [mccutchen/go-httpbin](https://github.com/mccutchen/go-httpbin) source
and runs the `go-httpbin` server on port 8080.
