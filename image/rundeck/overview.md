## About Rundeck

Rundeck is a runbook-automation and self-service operations platform. Operators define **jobs** (sequences of commands
or scripts) and run them across a fleet of remote **nodes** over SSH, on schedules or on demand, with role-based access
control, logging, and audit. It runs as a single JVM web application that serves a web console and REST API on port
4440, backed by an embedded H2 database out of the box or an external MySQL/PostgreSQL datastore for production.
